Agregar un nuevo caso

Estructura requerida (v2 — Investigacion Progresiva)

Cada caso debe incluir:

  • id, difficulty (Alto/Experto/Hardcore), title, description
  • objectives — array de strings
  • characters — cada uno con name, personality, testimony, truth (boolean), suspicionLevel ("high", "medium" o "low")
  • clues — objeto con phase1, phase2, phase3 (arrays de pistas)
  • Cada pista: { text, relevant, misleading, pointsTo?, contradicts? }
  • solution — con culprit, motive, method, consequence (ruta imagen), chronology
  • chronology — array de objetos { event: "...", clueHint: "..." }
  • debriefQuestions — array de preguntas de reflexion
